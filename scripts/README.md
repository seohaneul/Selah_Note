# 성경 데이터 파이프라인 (Data Pipeline)

이 디렉토리는 '말씀조각(Selah Note)' 모바일 앱에서 사용할 성경 데이터를 구축하기 위한 **파이썬 데이터 전처리 파이프라인(ETL)** 스크립트를 포함하고 있습니다.

모바일 클라이언트(Flutter) 내부에 무거운 텍스트 파싱 로직을 포함시키는 대신, 파이썬 스크립트를 통해 사전에 데이터를 JSON(NoSQL 형태)으로 변환 및 최적화하여 앱의 성능을 극대화하도록 설계되었습니다.

## 🛠️ 기능 요약 (Features)
- `.txt` 확장자로 된 성경 원본 텍스트를 읽어들입니다.
- 첫 번째 띄어쓰기를 기준으로 키(Key)와 본문(Value)을 분리하는 정규 파싱을 수행합니다.
- 추출된 데이터를 Dart(Flutter) 앱에서 즉시 사용할 수 있도록 경량화된 `JSON` 파일로 직렬화(Serialize)하여 내보냅니다.

## 🚀 사용 방법 (How to run)

1. 이 `scripts` 폴더 안에 `raw_data` 폴더를 생성합니다. (스크립트 실행 시 자동으로 생성됩니다.)
2. `raw_data` 폴더 안에 변환하고자 하는 성경 원본 `.txt` 파일들을 넣습니다.
   - 예: `raw_data/개역개정.txt`, `raw_data/새번역.txt`
3. 파이썬 스크립트를 실행합니다. (외부 라이브러리 의존성 없음)
   ```bash
   python bible_parser.py
   ```
4. `output` 폴더가 생성되며, 그 안에 파싱이 완료된 `bible_개역개정.json` 등의 파일이 추출됩니다.
5. 생성된 `.json` 파일을 Flutter 프로젝트의 `assets/` 폴더에 복사하여 사용합니다.
